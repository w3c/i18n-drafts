Chinese, Japanese, & Korean quotation marks

Intended audience: Content authors

Chinese, Japanese, and Korean use a variety of symbols to demarcate quotations. This article looks at which Unicode code points are used for horizontal and vertical text in those languages.

Key takeaways

✅ Reliable

Fully interoperable.

Simplified Chinese. Horizontal text uses either “...” or 『...』 as primary quotation marks. Vertical text uses 『...』. All punctuation is fullwidth. Some fonts automatically convert comma-style quotation marks to brackets in vertical text.

Traditional Chinese. Horizontal and vertical text uses 『...』 as primary quotation marks. All punctuation is fullwidth.

❌ Unreliable

No automatic support; styled behaviour inconsistent.

Spacing around alphabetic or numeric phrases. Browsers do not automatically insert the small gaps expected in Chinese/Japanese typography when Latin letters or numbers appear inside text. Attempts to style these gaps produce inconsistent results: Blink and Gecko behave differently, and WebKit only inserts a gap on one side. The “replace” behaviour (uniform spacing even when spaces exist) is not implemented, and currently breaks other behaviour when specified.

⚠️ Blink‑only

No support in Gecko/WebKit.

Collapsing space in runs of punctuation. Blink browsers collapse excessive spacing between adjacent punctuation marks by default. Gecko and WebKit do not collapse these gaps, and styled collapsing is only effective in Blink.

⚠️ Blink‑only & font‑dependent

Not supported in Gecko/​WebKit.

Collapsing line‑initial space. Blink reduces leading space for opening punctuation at the start of a line or paragraph, but results depend on the font. Gecko and WebKit do not reduce this space.

⚠️ Mostly Blink‑only

Not interoperable.

Collapsing line‑final space. Blink reduces trailing space for closing punctuation at the end of a line, helping it fit without wrapping. Gecko and WebKit do not implement this behaviour.

Scope & definitions

The quotation marks described here cover only the most commonly used punctuation for basic quotations (and quotations embedded within another quotation). Other characters or typographic approaches may be used for citations of book titles, proper names, etc., and those are not covered in the scope of this article. Sometimes, particularly in dialogues, quoted text doesn't use pairs of characters — such conventions are not covered here.

Often, different code points are used for horizontal and vertical text, but sometimes the alternative glyphs are produced using font-based rules, rather than different code points. Typically, when the same code points are used for horizontal and vertical text, font rules are used to rotate and sometimes shift glyphs within the character cell. It is also common for different punctuation marks to be used for quotes that are embedded within a quote.

In most cases, comma-like quotes or brackets are used. However, different fonts may use slightly different glyphs for the comma-like quotes: some may be curly, others more wedge-shaped. In addition, Japanese uses glyphs that look like primes.

Various aspects need investigation.

  1. What symbols are used for horizontal vs vertically-set text.
  2. How those symbols are aligned with the character box.
  3. Whether the symbols are fullwidth or proportionally-spaced (or halfwidth).

Simplified Chinese

Authors of Simplified Chinese texts may use either comma-like quote marks or brackets for horizontal text. However, vertical text (which is rare) uses only brackets.

Unicode code points:

  • “ U+201C: LEFT DOUBLE QUOTATION MARK
  • ” U+201D: RIGHT DOUBLE QUOTATION MARK
  • ‘ U+2018: LEFT SINGLE QUOTATION MARK
  • ’ U+2019: RIGHT SINGLE QUOTATION MARK
  • 『 U+300E: LEFT WHITE CORNER BRACKET
  • 』 U+300F: RIGHT WHITE CORNER BRACKET
  • 「 U+300C: LEFT CORNER BRACKET
  • 」 U+300D: RIGHT CORNER BRACKET

Width. All punctuation used for quotations is normally rendered fullwidth. This includes the glyphs for comma-like quotes. Although they are rendered as proportionally-spaced glyphs in most languages. No special, fullwidth code points are reserved for these comma-like quotes.

Width. All punctuation used for quotations is normally rendered fullwidth. This includes the glyphs for comma-like quotes. No special, fullwidth code points are reserved for the comma-like quotes; although they are rendered as proportionally-spaced glyphs in most languages, the Chinese fonts will usually render them as fullwidth.

Comma-like quotes and brackets may become halfwidth if they occur alongside certain other punctuation, or at line start/end. For details, see Managing inline spaces in Chinese & Japanese.

Rotation. Bracket glyphs are simply rotated in vertical text, but the code points used should remain the same. The Unicode Standard has a number of vertical presentation forms for the brackets, in the range FE41..FE44, but these should not be used; presentation forms are only for round trip conversions of legacy data.

Horizontal vs vertical conversion. The fact that comma-like quotes are not used in vertical text may give rise to a mismatch between expected shapes if text is restyled from horizontal to vertical, or vice versa. One way to manage this is to change the code points while converting between horizontal comma-like quotes and vertical brackets. Another is to use a font that automatically chooses an appropriate shape in addition to rotating the glyph — in which case, comma-like quote code points would be used throughout, but the font would apply the expected glyph during rendering.

This test checks whether glyph shapes are changed automatically for system and Noto fonts on macOS. Of the 23 fonts tested, only the following automatically substitute brackets for comma-like quotes: Noto Sans CJK SC, Noto Serif CJK SC, SimSong, Noto Sans CJK SC, Lantinghei SC.

This test checks whether glyph shapes are changed automatically for system and Noto fonts on Windows. Of the 9 fonts tested, only the following automatically substitute brackets for comma-like quotes: NSimSun, SimSun.

Traditional Chinese

Traditional Chinese texts, such as those used in Taiwan, normally use only brackets for horizontal and vertical text (which is more common than in Mainland China). However, the type of bracket used for primary and secondary quotations are the opposite to those used for Simplified Chinese.

Unicode code points:

  • 「 U+300C: LEFT CORNER BRACKET
  • 」 U+300D: RIGHT CORNER BRACKET
  • 『 U+300E: LEFT WHITE CORNER BRACKET
  • 』 U+300F: RIGHT WHITE CORNER BRACKET

Occasionally, Traditional Chinese text may use double brackets for the default, and single for the embedded. It may also use quotation marks, like Mainland China, but not commonly, and much less so for vertical text.

Width. All quotation punctuation is normally rendered fullwidth.

Comma-like quotes and brackets may become halfwidth if they occur alongside certain other punctuation, or at line start/end. For details, see Managing inline spaces in Chinese & Japanese.

Rotation. Bracket glyphs are simply rotated in vertical text, but the code points used should remain the same. The Unicode Standard has a number of vertical presentation forms for the brackets, in the range FE41..FE44, but these should not be used; presentation forms are only for round trip conversions of legacy data.

Japanese

Japanese texts may use comma-like quote marks or brackets for horizontal text. However, vertical text (which is common) uses either brackets or double primes (no comma-like quotes).

Unicode code points:

  • “ U+201C: LEFT DOUBLE QUOTATION MARK
  • ” U+201D: RIGHT DOUBLE QUOTATION MARK
  • ‘ U+2018: LEFT SINGLE QUOTATION MARK
  • ’ U+2019: RIGHT SINGLE QUOTATION MARK
  • 『 U+300E: LEFT WHITE CORNER BRACKET
  • 』 U+300F: RIGHT WHITE CORNER BRACKET
  • 「 U+300C: LEFT CORNER BRACKET
  • 」 U+300D: RIGHT CORNER BRACKET
  • 〝 U+301D: REVERSED DOUBLE PRIME QUOTATION MARK
  • 〟 U+301F: LOW DOUBLE PRIME QUOTATION MARK

Width. All punctuation used for quotations is normally rendered fullwidth, including the code points for the comma-like quotes, which are rendered as proportionally-spaced glyphs in most languages. No special, fullwidth code points are reserved for these comma-like quotes — the glyph width is applied by the font.

The Unicode Standard has a number of vertical presentation forms for the brackets, in the range FE41..FE44, but these should not be used; presentation forms are only for round trip conversions of legacy data.

South Korea

Korean texts in South Korea usually use comma-like quote marks for horizontal text. However, vertical text (which is rare) uses either brackets.

Unicode code points:

  • “ U+201C: LEFT DOUBLE QUOTATION MARK
  • ” U+201D: RIGHT DOUBLE QUOTATION MARK
  • ‘ U+2018: LEFT SINGLE QUOTATION MARK
  • ’ U+2019: RIGHT SINGLE QUOTATION MARK
  • 『 U+300E: LEFT WHITE CORNER BRACKET
  • 』 U+300F: RIGHT WHITE CORNER BRACKET
  • 「 U+300C: LEFT CORNER BRACKET
  • 」 U+300D: RIGHT CORNER BRACKET

Width. Horizontal text uses comma-style quotation marks, but they may be proportionally-spaced or fullwidth. No special code points are dedicated to indicate the width — the width is determined by the font used. The brackets used in vertical text are all fullwidth.

As just mentioned, many fonts render quotation marks using proportionally-spaced glyphs, however some other fonts render the same code points as full-width glyphs. If text content is written on the assumption that proportionally-spaced glyphs will be used, then a space character needs to be added next to the quotation mark. However, if the font is changed to one that renders the quotation mark as full-width, the adjacent gap will be quite large. Vice versa, content created with the expectation that quotation marks will be rendered full-width will have no gap alongside the quotation mark if the font is changed to one that uses proportionally-spaced glyphs. This means that Korean fonts are not as easily interchangeable as Chinese or Japanese fonts.

Rotation. Bracket glyphs are rotated and shifted in vertical text, but the code points used should remain the same. The Unicode Standard has a number of vertical presentation forms for the brackets, in the range FE41..FE44, but these should not be used; presentation forms are only for round trip conversions of legacy data.

North Korea

Texts in North Korea use angle brackets for quotation marks. Vertical text is not used in the north.

Unicode code points:

  • 《 U+300A: LEFT DOUBLE ANGLE BRACKET
  • 》 U+300B: RIGHT DOUBLE ANGLE BRACKET

Width. Quotation marks are rendered fullwidth.

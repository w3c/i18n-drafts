Translation status

This page shows which W3C Internationalization articles, tutorials, and other pages have not yet been translated, and which existing translations may need to be updated. Choose a language to see what needs work.

Before you start, please read the translation instructions and write to public-i18n-translation@w3.org. Someone may already be working on the page, or the English source may be about to change.

Translations that may need updating

A translation is listed here when it is flagged in the repository as out of date, or when the English page has been changed since the translation was last edited.

Pages not yet translated

Pages are grouped by type. If an archived translation is mentioned, an older version was withdrawn; it may still be a useful starting point, but check with the translation mailing list first.

Coverage by language

The table shows how many pages are translated into each language. Select a language name to see the details.

How this list is made

The lists are generated from the metadata of the pages. The translations.js file that accompanies each page records which translations are current and which are flagged as out of date, and each translated page records the date it was last edited.

Pages that are obsolete, or still in draft or review, are not listed. A translation whose English source was edited after the translation was last updated is listed as a precaution, even if the change did not affect the text.
